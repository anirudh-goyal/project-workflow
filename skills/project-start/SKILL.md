# Start project work

1. Find the notes folder in the user's request or CLAUDE.local.md. A path in that file is relative to the file; a supplied path is relative to the working directory. Ask about missing or conflicting locations. Use `/add-dir` when access is needed.
2. Read the project instructions and the notes folder's CLAUDE.md. If notes are missing, tell the user; preserve existing documents.
3. Read the design and any requirements/tasks. Inspect the relevant code, tests, and Git status. Record the codebase and notes paths in progress.md.
4. Briefly explain your understanding, open questions, and next steps. Help refine the design and turn agreed behavior into requirements and tasks when requested.
5. Continue the requested work, keeping notes updated throughout. Starting the workflow alone does not request application implementation.
