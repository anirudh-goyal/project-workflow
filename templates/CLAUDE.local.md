# Project documentation workflow

The notes directory is `../notes`, relative to this file.
The codebase directory is the directory containing this file.

Before planning or implementing project work, read the notes directory's
CLAUDE.md and follow its workflow throughout the session. On a fresh session,
use project-resume for existing work or project-start for new notes.

Keep the documents synchronized automatically as requirements, decisions,
implementation, verification results, and task status change. Update affected
sections as events occur; do not wait for a reminder or session end.

If the notes or workflow instructions are inaccessible, explain the access
issue. Do not silently create a replacement folder or continue work that
requires the missing context.
