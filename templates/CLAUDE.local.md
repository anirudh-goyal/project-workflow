# Project documentation workflow

My project notes are in `../notes`, relative to this file.
Read that folder's CLAUDE.md before planning or implementing work, and
follow its instructions throughout the session.

Use project-start when beginning the project and project-resume when
continuing in a fresh session. Keep notes updated automatically as work
progresses, without waiting for reminders or session end.

If the notes are inaccessible or missing, tell me; do not create a
replacement folder elsewhere.
